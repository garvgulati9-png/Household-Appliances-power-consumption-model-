2. Cross-Dataset Testing on Research Paper Dataset (Piedra Santa: 200 Records)

Cross-Validation Analysis

To evaluate model behavior when migrating from massive IoT continuous telemetry (N = 19,735 records) to small-scale urban survey micro-data (N = 200 households), we cross-tested all major regression architectures on the paper's dataset:

Tested Architecture MAE (kW) RMSE (kW) R² Test (30%) R² 5-Fold CV Cross-Dataset Finding
Support Vector Machine (SVR) 0.5447 0.6598 +0.0833 +0.1933 Best Small-Sample Generalization
Linear Regression (OLS) 0.5282 0.6709 +0.0524 +0.2545 Highest Cross-Validated Fit
XGBoost (Regularized) 0.5603 0.6751 +0.0404 +0.1872 L1/L2 Constraints Prevent Overfitting
Random Forest (Unconstrained) 0.5798 0.7073 -0.0532 +0.1699 Overfits Small Training Partition
Deep Neural Network (MLP) 0.7685 0.9231 -0.7941 -0.3827 Severe Over-Parameterization
Between-Groups SS 0.0712
Degrees of Freedom 4
ANOVA F-Statistic 6.253
p-Value 0.0020

Key Finding: With ANOVA F = 6.253 (p-value = 0.0020), the performance differences are statistically proven. Complex models require large-scale data (where our ensemble achieved 75.04%), while linear/kernel models are more resilient when restricted to small micro-datasets.
